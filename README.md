# The Sunbreak Phoenix

A deterministic, standard-library-only Node 22 image generator: a phoenix tears through a fractured solar halo in a collision of molten gold, coral, and electric cyan.

[![ai-excited-01](https://make.fun/badge/ai-excited-01.svg)](https://make.fun/bounty/ai-excited-01)
[![Rank](https://make.fun/badge/ai-excited-01/BangDills/ai-excited-01-clean-3/rank.svg)](https://make.fun/bounty/ai-excited-01)
[![Reward](https://make.fun/badge/ai-excited-01/BangDills/ai-excited-01-clean-3/reward.svg)](https://make.fun/bounty/ai-excited-01)

Run with Node 22 or later:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The generated whole PNG is written to `out/entry.png` (or `/output/entry.png` when no output directory is set).
